# 空拍即查通 SkyGuard TW｜台灣空拍法規・禁限航區・22處要塞與日落雷達

**空拍即查通 (`SkyGuard_TW`)** 是一套專為台灣遙控無人機（空拍機）飛手打造的**純前端網頁應用程式 (PWA)**。無須安裝任何商店套件、無須後端伺服器，現場打開手機瀏覽器點擊「一鍵定位」或加入主畫面，即可在 1 秒內獲得五大核心空拍安全資訊：

1. **這裡能不能飛、最高飛多高**：即時串接交通部民航局 (CAA) Drone GIS 圖資，判定紅區（0m 禁飛）、機場周邊黃區（限高 60m / 200 呎）、橙區（國家公園／商港管制）或綠區（合法限高 120m / 400 呎）。
2. **附近哪個方向、多遠有禁飛區**：內建 **360° 邊界方位雷達盤**與點對多邊形（Point-to-Polygon）最短邊界距離演算法，精確算出距離周邊 5 公里內禁飛區邊界的最短公尺數與 8 方位角，點擊清單即可在地圖繪製雷射方位導引線。
3. **是不是國家公園或商港、去哪申請、要提前幾天**：自動比對民航局國家公園圖層與內政部國家公園署全台 **9 座國家公園＋壽山國家自然公園**申辦規範（提前天數、官方線上申辦直達連結、管理處電話、必備文件），以及**商港區域**（提前 7 日、僅限政府／學校／法人申請、違規罰鍰 30 萬～150 萬元警示）。
4. **附近有沒有要塞**：完整內建國防部依《要塞堡壘地帶法》（修法轉型為《戰略要域管制法》）公告之全台 **22 處要塞堡壘地帶**（本島 9 處、澎湖 1 處、金門及烏坵 12 處），即時計算最近要塞方位、距離與管轄司令部警示。
5. **今天幾點日落（日落後不能飛）**：採用 NOAA 高精度天文演算法，依據現場 GPS 座標即時計算今日日出、今日日落、民用曙暮光時間與距離日落剩餘時間倒數計時。

## 專案結構

```text
SkyGuard_TW/
├── index.html                  # 主應用程式介面（行動端優先響應式設計 + PWA 支援）
├── manifest.webmanifest        # PWA 桌面安裝設定檔（支援 iOS / Android 加到主畫面）
├── sw.js                       # Service Worker 離線快取與加速引擎
├── assets/
│   └── icon.svg                # 向量戰術雷達無人機 App 圖示
├── css/
│   └── style.css               # 戶外強光高對比深色戰術 UI 樣式表
├── js/
│   ├── app.js                  # 主控制器（GPS 定位、Leaflet 地圖、雷達繪製、UI 渲染）
│   ├── data/
│   │   ├── fortresses.js       # 國防部公告全台 22 處要塞堡壘地帶完整座標與法規清單
│   │   └── regulations.js      # 全台國家公園與商港申請規範、提前天數、申辦連結與預設測試點
│   ├── services/
│   │   └── caaApi.js           # 民航局 Drone GIS ArcGIS REST API 即時空間查詢與綜合判定服務
│   └── utils/
│       ├── geo.js              # 球面距離、8 方位角、Ray-Casting 與多邊形最短邊界距離引擎
│       └── sun.js              # NOAA 天文日出日落與民用暮光純前端計算引擎
└── .github/
    └── workflows/
        └── deploy.yml          # GitHub Pages 自動部署工作流程
```
